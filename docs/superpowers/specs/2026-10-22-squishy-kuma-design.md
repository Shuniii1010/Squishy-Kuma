# Squishy-Kuma design

以用户 2026-10-22 的需求文档为验收依据。独立本地 Flask 项目，不更改 sources 或现有文书。

## Intended experience
奶油色背景，参考图的蜜糖棕圆脸、黄色内耳、奶白口鼻。按用户最新补充，程序生成仅有熊头和耳朵的厚实扁平捏捏玩具，不包含熊头与四肢，柔和哑光材质和地面阴影。桌面左侧手感面板，右上双语及声音，右下计数，底部提示；窄屏控制面板下移。

## Architecture
Flask 只在 127.0.0.1 提供页面和静态文件。Three.js 固定版本并随项目保存，运行无 CDN 请求。模型是高细分曲面，全部顶点烘焙到统一坐标。五官及内耳贴片使用母体曲面方程，所有顶点共享局部空间形变场，避免僵硬部件动画。

形变以有界高斯核位移场与固定子步弹簧阻尼积分实现。一次有效命中创建一个局部场，按下向内，拖动沿屏幕平面有界拉扯。柔软度决定目标形变量，回弹程度决定释放后的弹簧刚度和阻尼比。限制局部场总数和总位移，未激活场稳定后移除。无整只熊统一缩放替代变形。

## Interaction and state
左键捏捏，右键 OrbitControls 旋转，滚轮缩放。Pointer capture，pointerup/cancel/lostpointercapture、blur、隐藏标签页均释放。有效按下计一次。localStorage 存储 zh/en、音效开关、次数、柔软度、回弹、预设；存储不可用时仍可使用。复原只重置位移及速度，清零只清计数。所有文案在 i18n.js 中集中管理。

Web Audio 用户手势后懒初始化，合成挤压和弹动声，限制并发并使用增益包络与压缩，关闭时立即静音。失败不中断模型。

## Verification
Node 内置测试检查局部影响、软硬幅度、回弹差异、极端参数稳定性、拖拽限幅、计数与持久化及中英文案覆盖。Python unittest 验证 HTTP 页面及本地模块。浏览器检验模型外观、熊头不同位置形变、操作计数、设置切换、刷新、异常释放、窄屏和无网络依赖。提供 README、素材来源说明、测试记录、zip。
