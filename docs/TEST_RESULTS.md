## 审查与验证边界

独立代码审查覆盖状态、声音、局部形变、异常指针路径与视角交互。审查发现的桌面失焦后视角手势残留已修复，并通过真实 OrbitControls 回归测试。身体模型在审查后按用户新要求改成仅熊头，相应新增几何及贴合测试，浏览器重新验证最终模型。

- Web Audio 调度和开关逻辑已验证；未进行扬声器录音或主观听感评测。
- 失焦 / 隐藏 / 指针捕获丢失清理路径已代码审查，镜头取消有离线事件回归测试；没有对全部操作系统窗口切换组合进行端到端测试。
- 未做所有浏览器、旧显卡及高刷新率设备的兼容性与 FPS 基准测试。没有声称恒定 60 FPS。
- Windows 启动说明已提供，但未在 Windows 实机运行。
- 首版仅提供单指触屏捏捏，未提供多指镜头操作。
- 软体模型是有界局部近似，不模拟精确保体积或全面自碰撞。适度限幅是稳定性设计的一部分。
