# 实现记录

- 项目单独位于 squishy-kuma/，未改动 sources/ 或原有文书；当前目录不是 Git 仓库，未创建提交、分支或 PR。
- 依据完整需求直接实现，无外部发布，使用 Flask 绑定 127.0.0.1。
- 用户补充要求只要熊头，已移除身体和四肢；五官及内耳曲面贴合、共享形变仍保留。
- 地面附近的形变权重使用平滑固定，避免扁平熊头底面被压入地面。
- 为减少卡死视角风险，失焦与捕获丢失时通过公开 dispose/constructor 重新创建 OrbitControls，保留当前视角而清除内部手势。
- 手机仅提供单指捏捏，本版关闭多指镜头，并在说明及触屏提示中明确。桌面右键旋转与滚轮缩放保持。
- 所有界面文字集中在 i18n.js；英文品牌 Squishy-Kuma 作为名称保持不变。
- 独立代码审查已完成，重要桌面问题已修复；详细证据见 TEST_RESULTS.md。
